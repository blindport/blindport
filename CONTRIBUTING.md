# Contributing

Use the [issue tracker](https://github.com/blindport/blindport/issues) for bugs
and focused feature proposals. Security reports must follow [SECURITY.md](SECURITY.md).

## Development

Blindport requires Python 3.11 or newer, Bun 1.3.11, and Go 1.26.5. Follow the
setup and test commands in [README.md](README.md). Keep changes focused, add
regression coverage, update operator documentation when behavior changes, and
run the relevant test suites plus `prek run --all-files` before opening a pull
request.

Use clear Conventional Commit subjects. By submitting a contribution, you agree
that it is licensed under the repository's [MIT License](LICENSE).
