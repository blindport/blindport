        1. Prepare framed mode
        
Creates owner-only user directories and prompts for the token without putting it in shell history. Copy the generated mapping above and save it as ~/.config/blindport/config.json.

        install -d -m 700 "$HOME/.config/blindport" "$HOME/.local/state/blindport" && bash -c 'read -rsp "Blindport token: " token && printf "\n" && printf "%s\n" "$token" | install -m 600 /dev/stdin "$HOME/.config/blindport/token"'
        
      

      

        2. Run framed mode
        blindportd -backend={{ request.url.scheme }}://{{ request.url.netloc }} -config="$HOME/.config/blindport/config.json" -token-file="$HOME/.config/blindport/token" -state-dir="$HOME/.local/state/blindport"
        
      

      

        WireGuard setup
        
WireGuard requires root-owned credentials and network administration capability.

        sudo install -d -m 700 /etc/blindport /var/lib/blindport && bash -c 'read -rsp "Blindport token: " token && printf "\n" && printf "%s\n" "$token" | sudo install -m 600 /dev/stdin /etc/blindport/token'
        
      

      

        Run WireGuard mode
        sudo blindportd -wireguard -backend={{ request.url.scheme }}://{{ request.url.netloc }} -token-file=/etc/blindport/token -state-dir=/var/lib/blindport
